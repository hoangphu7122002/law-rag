# L40S box

2× L40S 46 GB, shared with other projects. ssh alias `l40s` (`app@100.101.115.108`, Tailscale).
Settings: `box:` block in `configs/backends/l40s.yaml`. Code: `src/ops/box.py` (`RemoteBox`).

**Rules:** touch only `/home/app/phunguyen/law_rag` and tmux sessions `lawrag-*`.
A GPU with < `min_free_mib` free is refused. No GPU run without the user's word; log it in `compute-log.md`.

```bash
make box ARGS="autosync on"                          # launchd agent: every saved file is pushed within ~2 s (log data/runs/logs/autosync.log)
make box ARGS="autosync off"
make box ARGS=push                                   # one manual rsync of code (no data/, .git, .venv, .cache)
make box ARGS=push-data                              # rsync data/raw (once)
make box ARGS=setup                                  # uv env, make data, make test (once)
make box ARGS="serve Qwen/Qwen1.5-1.8B --gpu 0"      # vLLM in tmux lawrag-vllm-g0, port 8000 (+gpu)
make box ARGS="run configs/exp/B0_baseline.yaml --gpu 0 --set split=test"   # tmux lawrag-run-B0_baseline
make box ARGS=status                                 # GPU memory, our sessions, last ledger rows
make box ARGS="stop vllm-g0"                         # kill one of our sessions
make box ARGS=pull                                   # runs back to data/runs/, ledger rows merged
make box ARGS=tunnel                                 # Mac localhost:8000/8001 -> box vLLM (Ctrl-C to close)
```

Logs on the box: `data/runs/logs/{vllm-g<gpu>,<exp>}.log`.

Autosync also pushes while a run is going; modules a run imports later (lazy imports) come from the new code.
