# Findings: legal tool value (agent summary; thin, indirect, unverified past snippets)
- (a) Statute lookup / agentic search: LegalSearch-R1 (7B RL agent, local statute retrieval + web search; +12.9–29.8 % over deep-research agents and legal LLMs on 13 legal tasks; self-reported, arXiv id unconfirmed); an RL-trained 14B legal document search model beat frontier 85 % vs 78 % — tool access alone was not enough, training to use the tools was; small models often fail to use supplied statute text, fixed by fine-tuning on prompts that include it (huggingface.co/papers/2607.23446); LLMs struggle to reproduce provisions faithfully → lookup over recall. LegalAgentBench (37 tools, arXiv 2412.17259) is a benchmark, not a gain.
- (b) Neighbour / citation graph: Louis et al. EACL 2023 GNN over code hierarchy improves statutory article retrieval (arXiv 2301.12847, numbers not seen); Indonesian ITE Law RAG hybrid RRF + citation-graph expansion recall .948 / full-hit .875 with a quantity-matched control, authors say needs validation (gain may be retrieving more chunks, not graph structure); ViHERMES / VLQA Vietnamese multi-hop regulation QA with graph-aware retrieval (arXiv 2507.19995). No small-vs-large split.
- (c) Amendment / temporal: VLegal-Bench tests amendment tracking (no numbers seen); ALQAC 2021 labour-law subset flags temporal drift (arXiv 2609.27376); no paper with quantified gains from a validity-lookup tool (gap).
- (d) Web search at inference: Stanford RegLab/HAI hallucination 17 % Lexis+ AI, 33 % Westlaw, 43 % GPT-4 (closed-corpus RAG vs bare LLM, not web search); Legal Research Bench (413 US questions): best model 42.9 % fully correct, more turns / tool calls / cost did not predict accuracy (arXiv 2610.00609); no direct evidence for web search.
- Small vs large: 7B–14B models gain from tools only after RL / fine-tuning on tool or context use; prompting alone is weak; no clean ablation by model size.
- Best supported: statute retrieval + fine-tuning small models to use retrieved text. Weak: graph expansion (confounded by retrieval depth), amendment tools, web search.
