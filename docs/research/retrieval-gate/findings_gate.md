# Findings: gate for "is the retrieved context sufficient?" (from subagent; read from snippets only, numbers NOT verified against full papers)

- Classic post-retrieval QPP (NQC etc.) degrades on neural rankers (Faggioli et al.: significantly worse on neural IR, up to ~10% on passage retrieval vs BM25). Fixes: entropy of top-k scores, query-variant QPP (Datta et al., up to ~20% on MonoT5), coherence-based dense QPP. No numbers found for QPP used as a RAG gate. https://arxiv.org/pdf/2302.09947v1.pdf https://arxiv.org/pdf/2310.11405
- Adaptive-RAG: T5-Large classifier routes no-retrieval / single-step / multi-step; labels auto-generated from which strategy answers correctly; accuracy ~54.5% 3-way (third-party summary, verify); T5-Small vs Large minimal difference; looks only at the query (complexity gate, not sufficiency gate). https://arxiv.org/pdf/2403.14403
- CRAG: lightweight fine-tuned T5 evaluator scores (query, doc) pairs, thresholds -> correct / incorrect / ambiguous; incorrect triggers web search; PopQA acc (LLaMA2-7b): plain RAG 50.5->54.9, Self-RAG 54.9->61.8 with CRAG; independent reproduction with Phi-3-mini 51.4->54.4. https://arxiv.org/abs/2401.15884
- Self-RAG: fine-tunes the generator to emit reflection tokens (needs a trained LLM, not a cheap add-on). https://arxiv.org/pdf/2310.11511
- FLARE: training-free, needs token logprobs and a draft, cannot gate before generation.
- Google "Sufficient Context" (ICLR 2025): autorater (prompted Gemini 1.5 Pro) labels context sufficient/insufficient, >=93% accuracy per blog; selective generation with a small model combining the sufficiency label and generator confidence gives 2-10% more correct answers among answered; models often answer wrongly rather than abstain when context is insufficient. https://arxiv.org/pdf/2411.06037
- Calibration/threshold: no concrete source. Own suggestion: fit logreg/GBM, calibrate (Platt/isotonic), choose threshold at a target on the selective-accuracy vs coverage curve, check on held-out data.
- Small classifier vs heavier: no direct comparison. Indirect support: CRAG's small T5 beats ChatGPT as relevance judge; Adaptive-RAG shows size matters little; Sufficient Context gate is a small model. Against: raw score statistics predict poorly on neural rankers -> modest AUROC from reranker-score features alone. Best-supported design: small classifier over several feature groups (top-k reranker scores, margin/entropy, dense-vs-rerank agreement, query features, a cross-encoder sufficiency score), validated against sufficiency labels.
