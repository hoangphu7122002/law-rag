# ADR-0001 — Project key: beat the baseline fairly, then add one unusual idea

**Status:** draft (2026-10-31)

Grade weight: 3 pts for measurable gain, 3 pts for explaining the method with numbers. So every idea must show
a number on the same `test` split with the same metric code. Order: fix the cheap wins first (structure-aware
chunks, hybrid retrieval, reranker, instruct model + answer template), then one distinctive idea (law graph /
Graph RAG, or LoRA fine-tune on `train`) chosen after research.
