# Findings: recipes and fair evaluation (agent summary; thin, secondary sources; unverified marked)
- Hard negatives: NV-Embed hard-negative mining BEIR 59.22 → 61.52; synthetic data only +0.24 MTEB (arXiv 2405.17428). Positive-aware filtering: unverified (check NV-Embed Sec. 3). Vietnamese legal (arXiv 2507.14619): semi-hard negatives beat plain hard (hard can hurt); no quantified false-negative-filter gain for legal.
- Synthetic queries: BKAI (arXiv 2412.00657): LLM queries, drop passage-quoting / shallow ones, pretrain bi-encoder + ColBERT, then fine-tune with BGE-M3-mined hard negatives ("strong improvement", no numbers seen). Qwen3-Embedding: Qwen3-32B ~150M pairs, cosine > 0.7 filter → ~12M for SFT, removing the weak-supervision stage = clear drop (secondary source). E5-mistral ~500K GPT pairs.
- LLM embedders + LoRA: Linq-Embed-Mistral LoRA r16 alpha32 all-linear (arXiv 2412.03223); F2LLM matches SOTA with 6M open data (arXiv 2510.02294).
- Listwise distillation: Rank-DistiLLM (RankZephyr → cross-encoders) matches LLM rerankers at far lower cost; listwise losses gave no benefit over pairwise (arXiv 2405.07920); RankGPT recipe BM25 top-20 reranked by GPT-3.5 on 10k MS MARCO queries (arXiv 2312.16098) → ~10k queries enough to start, pointwise/pairwise loss on teacher ranks is fine.
- Not found: bge-m3 multi-vector/sparse FT gains, domain-adaptive pretraining for legal retrieval, matryoshka, 1k–100k gain curves, COLIEE / statute baselines.
- Forgetting: weight interpolation base ↔ fine-tuned (WiSE-FT; LM-Cocktail; LiNeS arXiv 2410.17146); alpha ~0.5–0.8 unverified; LoRA, general-domain replay.
- Fair comparison vs an existing fine-tuned model: same candidate pool / corpus / chunking / first-stage retriever; same split, dedupe + decontaminate synthetic data and teacher prompts, tune on dev only; article-level Recall@k, MRR@k, nDCG@k (aggregate chunk hits to article); per-query paired tests (paired t / permutation; paired bootstrap can be biased toward small p at low n, arXiv 1905.11096), CIs, Holm / Bonferroni for many comparisons; report the non-fine-tuned base row and an out-of-domain set for forgetting; match compute/data budget or state it; multiple seeds.
