# Findings: generation side (agent summary, snippets only; unverified)
- MBR with ROUGE: Suzgun et al. 2023 (aclanthology findings-acl.262): +3–7 ROUGE/BLEU points across tasks incl. summarization (N and model sizes unverified; typical N ≈ 8–32). Wu et al. ICLR 2025 (arXiv 2410.02902): lexical/embedding utilities give small, inconsistent or negative gains on instruction following; LLM-judge utility much better; MBR consistently beats best-of-N. Helps most when metric = eval metric and answers are short/extractive. No small-LLM RAG-QA MBR number found.
- RAFT (Zhang 2024, arXiv 2403.10131): oracle + distractor docs + chain-of-thought quoting source beats oracle-only; best train docs 4 (NQ) / 2 (HotpotQA). Rejection-sampling FT / STaR / ReST for RAG: no hits. CaLF (arXiv 2406.13124): filter sampled responses with a consistency model, FT on them (+34.1 citation F1 vs ICL, +15.5 vs FT).
- Merging: model soups (Wortsman 2022) gains mainly from checkpoints with different hparams/seeds from the same init; WARP/WARM (secondary). Merged checkpoints ≈ best single checkpoint (blog). No controlled study for <4B SFT with ROUGE.
- Citation-aware: FRONT (ACL Findings 2024, +14.2 % citation quality, unverified), ReClaim (2407.01796), Ground-GRPO (2506.15522: grounding + refusal reward; distillation wins list QA, RL wins long-form). These measure citation F1, not ROUGE.
