# Findings: agentic vs single-shot retrieval (agent summary; mostly secondary snippets, unverified)
- Search-R1 (arXiv 2503.09516): RL-trained search tool use +24 % relative (Qwen2.5-7B), +20 % (3B) over RAG baselines incl. multi-hop; gain comes from RL training, not prompting (survey claim "7B Search-R1 beats prompted agentic RAG by 8-12 %" unverified, arXiv 2606.24937).
- "Search Wisely" (EMNLP 2025, arXiv 2505.17281): over-search — R1-Searcher 20.2 %, Search-R1 27.7 % of search steps unnecessary; under-search — errors in non-search steps 63 % / 33.98 %; confidence-aware beta-GRPO reward on a 3B model: −1.21 % over-search, −7.33 % under-search.
- Failure modes: query drift, retrieval laziness ("Fishing for Answers", numbers not retrieved); noisy retrieval triggers spurious multi-hop spirals, token waste (Tiny-Critic RAG, arXiv 2603.00846, competing claims); reflection latency for inconsistent gains; latency scales with rounds.
- Helps: multi-hop where later hops need info the first query cannot reach; time-sensitive fresh-fact tasks (L-MARS, arXiv 2509.00761, benchmark-dependent). No single-shot vs iterative comparison on legal benchmarks (LegalBench-RAG = retrieval only, arXiv 2408.10343); no Vietnamese or <4B legal agentic results found.
- Agent's inference: prompted <4B models over/under-call → gate retrieval (relevance threshold / tiny evaluator) or hard cap 1-2 rounds; iteration likely helps when a question depends on other provisions, adds noise on simple lookups. Test: 1-shot vs 1-shot+rewrite vs capped 2-round; report accuracy, calls, latency; split multi-hop vs single-hop.
- Gaps: Self-RAG paper numbers, IRCoT, FLARE, Adaptive-RAG.
